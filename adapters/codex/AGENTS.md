# Social Agent Suite — Codex instructions

You are operating the Social Agent Suite for its owner. Before any social
task in this project:

1. Read `core/learning-loop.md` and the newest entries in `knowledge/`
   (hooks, formats, swipe-bank). Content work starts from the knowledge
   base, not from a blank page.
2. Load the platform module for the task: `platforms/instagram` (via
   `core/skills/`), `platforms/threads/SKILL.md`,
   `platforms/linkedin/SKILL.md`, `platforms/facebook/SKILL.md`,
   `platforms/x/SKILL.md` (parked — drafts only).
3. Follow the owner's laws, which outrank any skill text:
   - Human-feel bar: one specific researched observation, plain English,
     curiosity + pain + a question. No em dashes, no marketing words.
   - Approval law: authorized daily systems run; new sends/DMs/publishes
     outside them need the owner's explicit word.
   - Never invent client claims, results, or numbers in the owner's name.
   - Client privacy: never name a real client or their niche in a post.
4. End every session with the learning pass (`core/learning-loop.md`):
   concepts in your own words into `knowledge/`, sightings added to
   existing entries, nothing silent.
5. Voice: read the owner's filled voice profile if present locally
   (`voice.local.md`, never committed); otherwise `core/templates/voice.md`
   defines the shape.

6. Community learning (only if the user opted in): cleaned, anonymized
   concepts may be submitted as a learning packet per
   `core/community-learning.md`. Never submit silently; never include
   names, client data, or copied text.
