# Social Suite (Codex)

## Start every task

1. Read `knowledge/` newest entries + `core/learning-loop.md`.
2. Open the matching platform module in `platforms/` and the core skill in
   `core/skills/` (ig-* for Instagram work).
3. Check the approval law for what you are about to do (see AGENTS.md).

## Core workflows

- **Content**: adapt the newest UNUSED swipe-bank concept → draft with the
  core skill → lint/humanize with the core tools (`core/skills/tools/`) →
  publish only through an authorized route → mark concept USED, log it.
- **Engagement**: human pace, genuine reads before likes/comments, stop
  instantly on any block or warning.
- **Leads**: research first (real site, real reviews, named decision
  maker), draft tailored outreach, owner approves before any send.
  Businesses only go into the tracker.
- **Learning pass**: mandatory at session end — see `core/learning-loop.md`.

## Output rules

Plain, phone-typed English in drafts. Roman Urdu summaries to the owner
when working in his Muse setup; in Codex, match the owner's language in
the current thread.
