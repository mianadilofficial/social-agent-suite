# Workflow: daily content cycle

1. Read `knowledge/swipe-bank.md` — pick the newest UNUSED concept that
   fits today's hook-type slot (rotate: debate/binary, mistake list,
   story, keyword, myth-bust — never yesterday's type).
2. Build the Instagram carousel per `adapters/muse/social-ig-content`
   rules (v2 realistic-scene style, ≤8-word cover hook, debate/binary
   final slide, caption ends with the question).
3. Brand-check every slide (real face unchanged, "by Mian Adil" watermark,
   "portfolio.mianadil.site" exact) at full size and 360px.
4. Publish through the authorized route; story from slide 1 with the link
   sticker; Threads gets the same carousel (short caption, question last).
5. Mark the concept USED with today's date; log the post in the content
   log; run `learning-pass.md`.
