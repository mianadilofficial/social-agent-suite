# Workflow: learning pass (end of every session)

1. List what this session actually saw: posts, patterns, facts, platform
   changes — with platform, author, date, engagement signal.
2. Rewrite each item as a concept in your own words. No copied text, ever.
3. File into `knowledge/`: hooks.md / formats.md / niche-notes.md /
   platform-changes.md / swipe-bank.md (new concepts UNUSED).
4. If a pattern already has an entry, add today's sighting to it —
   repetition is what earns promotion.
5. Weekly only: promote 3+-sighting patterns into the skill files and log
   every promotion in `knowledge/CHANGELOG.md`. Never silent.
