# Social Audit (Muse adapter)

Audit the owner's own social accounts (or a prospect's, for outreach
research) using the suite core audit skills plus Muse's live routes
(instagram-cli insights, threads-cli, browser) — real numbers only.

## When to use

The owner asks how an account is doing, why reach is low, or for a periodic
review; also before changing any daily system (audit first, change second).

## Workflow

1. Pull real metrics from the live routes (e.g. Instagram insights via
   instagram-cli: views, reach, profile visits, follows over 28 days;
   per-post numbers for the recent set). Browser-check anything the CLIs
   cannot give. Never estimate a number you can measure.
2. Compare against the recorded baseline in `knowledge/formats.md` and the
   last audit. Say plainly what rose, what fell, what is noise.
3. Diagnose by format first (the niche evidence: carousels reliable,
   singles weakest, reels high-variance), then by hook type, then by topic.
4. Recommend at most three changes, each tied to a measured problem, with
   the check-back date. System changes are the owner's call.
5. File the audit summary into `knowledge/niche-notes.md` (dated) so the
   learning loop compounds it.

## Rules

Verify before reporting — a worker's or a dashboard's claim is not evidence
until checked against the live source. No vanity metrics dressed as growth.
