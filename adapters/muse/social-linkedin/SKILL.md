# Social LinkedIn (Muse adapter)

Run the LinkedIn module (`platforms/linkedin/SKILL.md`) through Muse's
hands: the signed-in browser for sessions and publishing, the tracker
sheet for business records, the swipe file for post concepts.

## When to use

A growth session is due, a post is due (alternate-day rule), comment
replies need handling, or the owner asks for LinkedIn work.

## Route notes

- Sign-in check is only "feed loads vs sign-in form". If the form shows,
  sign in with the saved Secure Vault login. Never name which profile is
  signed in — sessions run on the signed-in profile, period.
- Publishing: browser post composer; poster file must be granted to the
  task or attached by the owner — if the poster cannot be attached,
  publish text-only and report the gap plainly.
- Tracker: LinkedIn tab of the Social Media Business Tracker; businesses
  only; status updated the same day.
- Summaries: brief Roman Urdu, delivered to the Social Media Manager chat.

All session rules (rotation, caps, warm-up, comment law, lead standard)
live in the platform module. Follow it exactly.
