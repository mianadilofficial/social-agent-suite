# Social Plan (Muse adapter)

Build the owner's weekly content plan across Instagram, Threads, LinkedIn
and Facebook from the suite's evidence base, and keep the daily systems fed
with topics so no run ever starts from a blank page.

## When to use

The owner asks for a content plan, a week of topics, or "next post kya ho";
also at the weekly upgrade rollup, when next week's mix is set.

## The weekly mix (evidence-based, from the niche study + owner's rules)

- Instagram/Threads (daily carousel): ~2 debate/binary, 1 mistake list,
  1 personal story, 1 keyword-exchange (CHECK), rest myth-busting/hot-take.
  Never repeat yesterday's topic or hook type.
- LinkedIn: alternate-day posts, discussion-first, poster per brand rules.
- Facebook profile: mirrors the LinkedIn/IG content family (owner attaches
  images himself).
- One reel slot per week (highest ceiling; see `social-reel`).

## Workflow

1. Read `knowledge/` (hooks, formats, swipe-bank UNUSED concepts first),
   the content log (what shipped, what it earned), and the owner's current
   real material (client-safe, anonymized).
2. Draft the week: date, platform, hook type, topic, format, source concept.
3. Topics must match the owner's field (web design, SEO, AI, small
   business) — his own data is welcome but not required. Invented client
   claims or results are banned in every slot.
4. Present the plan in one compact list. On approval, stage topics where
   the daily systems read them.

## Rules

Planning never publishes. Changes mid-week follow the same evidence: a
format that keeps earning gets more slots; two flops retire a hook type to
the changelog with a note.
