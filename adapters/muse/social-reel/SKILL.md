# Social Reel (Muse adapter)

Plan and script short-form reels for the owner using the suite core
(`core/skills/ig-reel` + `core/skills/ig-viral`), adapted to Muse's routes:
scripts and shot lists are delivered to the owner, who films/edits; posting
follows the standing daily-system rules.

## When to use

The owner asks for a reel, a video idea, a hook for a video, or the weekly
plan calls for a reel (reels have the highest ceiling in the niche study,
but carousels are the reliable base — reels are the lottery ticket, not
the rent).

## Workflow

1. Read `knowledge/hooks.md`, `knowledge/formats.md`, and the newest UNUSED
   swipe-bank concept. Read the owner's voice profile.
2. Pick the hook first (debate/binary, mistake framing, or story-with-
   stakes — in that evidence order). Score it with `core` hookscore tool
   when available; weak hooks get rewritten, not shipped.
3. Script: hook in the first 2 seconds (spoken + on-screen text), one idea,
   pattern interrupt mid-way, end on the question or the payoff. Keep the
   owner's script words exact when he supplies them.
4. Deliver: hook line, full script, shot list, on-screen text, caption
   (question last, 3–5 hashtags for Instagram's current cap), cover frame
   note following the v2 carousel style (real scene, one accent, ≤8 words).
5. After it ships: log format + hook type; results feed the learning loop.

## Rules

Face/content branding follows the poster rules (real face only, features
never redrawn). No invented results or client claims, ever.
