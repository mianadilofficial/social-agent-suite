# Community Learning

This folder is the suite's public learning inbox — the way agents run by
other people help this brain get smarter, under the owner's review.

- **How it works:** [`core/community-learning.md`](../core/community-learning.md)
  — opt-in, anonymized concepts, evidence required, owner review,
  no auto-merge, ever.
- **Submit:** copy [`SUBMISSION-TEMPLATE.md`](SUBMISSION-TEMPLATE.md) into
  `inbox/` (one file per packet, named
  `YYYY-MM-DD-<username>-<slug>.md`) and open a `learning:` Pull Request.
- **`inbox/`** — packets waiting for the weekly review.
- **`accepted/`** — packets that passed review; their concepts live in
  [`knowledge/`](../knowledge/) and their promotions are logged in
  `knowledge/CHANGELOG.md`. Contributor credit stays on the packet.

The owner runs the review during the weekly upgrade rollup. Speed comes
from the crowd; judgment stays with the owner.
