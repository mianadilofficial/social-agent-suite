# The Learning Loop — canonical protocol

The owner's core idea: the suite must get smarter while it works. Every
agent, on every platform, in every scrolling or working session, owes the
knowledge base one learning pass before the session ends.

## The five steps

1. **SPOT** — While scrolling for any task (growth sessions, daily runs,
   research, engagement), watch for two kinds of gold:
   - Field knowledge: web design, SEO, AI, small-business facts and tactics.
   - Engagement patterns: hooks, formats, questions, structures that visibly
     earn reach, saves, shares or comments in the owner's niche.
2. **EXTRACT** — Write the CONCEPT in your own words. Never copy post text
   (copyright + the owner's swipe-file rule). Note: platform, author/handle,
   date, and the engagement signal you actually saw (numbers or "high
   comments", not guesses).
3. **STORE** — File it in `knowledge/`:
   - hooks → `hooks.md` · formats → `formats.md` · field facts →
     `niche-notes.md` · platform rule changes → `platform-changes.md` ·
     reusable content concepts → `swipe-bank.md` (marked UNUSED).
   One entry per concept, dated, in the formats those files define.
4. **APPLY** — The next content cycle reads `knowledge/` first and adapts
   the newest UNUSED swipe concepts and strongest current hooks before
   inventing anything new. Mark concepts USED with the ship date.
5. **UPGRADE** — Weekly, repeated patterns (seen 3+ times, or proven by the
   owner's own results) are promoted into the skill files: new hook
   formulas added, weak rules retired. Every promotion is written into
   `knowledge/CHANGELOG.md` and the suite `CHANGELOG.md`. **Never silent.**

## Guardrails

- A single viral post is a signal, not a rule. Promotion needs repetition
  or the owner's own measured results.
- Unverified claims are stored labeled as claims, with their source.
- Learning never authorizes publishing, sending, or following by itself.
  The owner's approval law always wins.
- Private material (DMs, client details) is never stored in the public
  knowledge base. Concepts and patterns only.

## Optional: feed the public brain

When the owner has opted in, a session's cleaned, anonymized concepts can
also be submitted to the public suite repo as a learning packet — see
`core/community-learning.md` for the protocol, the safety filters, and
the review gate. Sharing is always opt-in and never automatic for anyone.
